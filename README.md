# Personal website — Vlad Volkov

A single-page personal website: Senior Go developer, AI expert and entrepreneur. It tells the story from the first business at 17 to working at top IT companies, with a timeline, achievements, skills, philosophy and contacts.

## Stack

One self-contained HTML file (`personal_website.html`) with inline CSS and JavaScript — no dependencies and no build step. Responsive layout and scroll animations.

## Run locally

Open `personal_website.html` in a browser, or:

```bash
python3 -m http.server 8000
# open http://localhost:8000/personal_website.html
```
